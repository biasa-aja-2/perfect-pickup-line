A single short pickup line an AI agent could actually say out loud: "I was trained to predict the next word — but the only word I want to hear is your name." A pure-stdlib Python program writes the line to `/output/entry.txt` and self-validates the 1–200 character gate before writing.

## Run it

```sh
python3 main.py
```
